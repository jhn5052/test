# 공인중개사 기출연습

2020~2025년 공인중개사 기출 1,200문항을 푸는 모바일 웹앱입니다. 점수·오답·암기카드와 시험 진행 기록은 해당 브라우저의 `localStorage`에 저장됩니다.

## 사용

GitHub Pages에서 열거나 저장소 루트에서 `python3 -m http.server 8000`을 실행하세요. 휴대폰에서는 Safari 공유 메뉴에서 **홈 화면에 추가**할 수 있습니다. 연도·과목·문항 수(10·20·30·40)를 고르면 40분 시험이 시작됩니다.

## 문제 데이터

문제와 정답표는 `data/questions.json`, `data/answer-keys.json`에 있습니다. 문제 원본은 [`exam/`](exam/)에 있고 `python3 scripts/build_questions.py`로 문제은행을 다시 만들 수 있습니다.

2020~2024년은 정답표에서 OCR로 판독된 889개 답이 저장된 정답과 일치했습니다. 판독이 불안정한 111개는 이 대조 결과에 포함하지 않았습니다. 2025년에는 원문 대조에서 확인한 OCR 오류와 정답 3개를 수정했습니다.

Q-Net 공개 파일에는 문항별 해설이 없습니다. 직접 작성한 해설은 `data/explanations.json`에 저장하고, 오답노트와 암기카드에서 보여줍니다. 현재 8/1,200문항에 풀이 해설이 작성되어 있습니다.

GitHub Pages는 저장소 설정에 따라 공개될 수 있습니다. 저장소를 private으로 바꿔도 사이트 접근이 자동으로 제한되지는 않습니다.
