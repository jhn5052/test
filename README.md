# 기출의 결

공인중개사 기출을 브라우저에서 풀고, 성적과 오답을 기기에 저장하는 정적 학습 앱입니다. 문제 풀이와 기록 관리는 브라우저에서 동작합니다.

## 실행

저장소 루트에서 로컬 서버를 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 브라우저의 보안 제한 때문에 `index.html`을 파일로 직접 여는 대신 서버를 사용해야 합니다.

## 기능

- 연도별 전과목 혼합 또는 단일 과목 시험, 문제 순서 셔플, 40분 타이머
- 일시정지와 재개, 이전/다음 이동, 답안 현황, 수동 제출과 시간 초과 자동 제출
- 자동 채점, 과목별 정답률, 오답노트, 회차별 성적 대시보드
- 시험 진행, 결과, 오답을 `localStorage`에 저장
- 확인 모달을 통한 전체 기록 초기화

기출 원문과 정답 데이터는 [jhn5052/test](https://github.com/jhn5052/test) 자료를 바탕으로 만들었습니다. 해당 저장소에는 일부 이미지 PDF와 스캔 파일이 포함되어 있어 문제와 정답 데이터는 기계 추출 과정에서 빠지거나 잘못 읽힐 수 있습니다. 원문에는 별도 해설이 없어 오답노트에는 정답표 기준 채점 정보가 표시됩니다.

## GitHub Pages 배포 및 휴대폰에서 사용

이 앱은 정적 HTML/CSS/JavaScript로 동작하므로 GitHub Pages에 배포할 수 있습니다. 저장소에서 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택한 뒤 기본 브랜치에 push하면 `.github/workflows/pages.yml`이 사이트를 배포합니다. 배포가 끝나면 같은 Pages 화면에 표시되는 주소를 휴대폰에서 엽니다. Safari 공유 메뉴의 **홈 화면에 추가**를 선택하면 앱처럼 바로 열 수 있습니다.

GitHub 저장소를 private으로 설정해도 게시된 Pages 사이트는 기본적으로 인터넷에 공개됩니다. 저장소 공개 여부와 사이트 접근 권한은 별개입니다. 사이트와 기출 데이터를 누구나 볼 수 있어도 괜찮을 때 이 구성을 사용하세요. 시험 이력과 오답 기록은 각 휴대폰 브라우저의 `localStorage`에 저장되므로 다른 방문자나 다른 기기와 공유되지 않습니다. 단, 브라우저 데이터를 지우거나 다른 브라우저를 사용하면 해당 기기의 기록에 접근할 수 없습니다.

문제 은행과 앱 코드는 GitHub에 보관하고, 풀이 이력은 휴대폰 브라우저의 `localStorage`에 남습니다. 이 기록은 서버로 전송되지 않습니다. 기기 간 기록 동기화가 필요하면 인증을 갖춘 별도 API를 추가해야 합니다.
