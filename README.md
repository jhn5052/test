# 공인중개사 기출연습

2020~2025년 공인중개사 기출 1,200문항과 2026년 예상문제를 모바일에서 풀고 복습하는 웹앱입니다. 과목 연습은 10·20·30·40문항으로 구성하고, 등록된 한 회차의 문제가 과목별로 모두 확인된 경우 1차(80문항·100분), 2차 1교시(80문항·100분), 2차 2교시(40문항·50분) 실전 모드를 제공합니다. 정답·해설·오답노트·개념 암기카드·과목별 성적·필수 암기(음성 듣기 포함)를 사용할 수 있습니다.

시험과 기록은 사용 중인 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 브라우저로 자동 동기화되지 않습니다. Pages 링크에서 열거나, 저장소 루트에서 `python3 -m http.server 8000`을 실행해 사용할 수 있습니다.

문제 원본과 최종 정답표는 [`exam/`](exam/)에, 문제은행은 [`data/questions.json`](data/questions.json)에 있습니다. 암기카드는 외울 개념·수치를 회상한 뒤 연결 기출로 확인하는 방식이며, 시험에서 틀린 문제 카드도 같은 화면에서 복습할 수 있습니다. 개념 카드 내용은 [`data/study-types.json`](data/study-types.json)에서 관리하고, 오답노트에서 관련 개념으로 이동할 수 있습니다. 세법·법령 숫자는 카드에 표시된 기출 회차 및 자료 기준을 확인하세요. 문제은행은 `python3 scripts/build_questions.py`로 다시 생성할 수 있습니다.

필수 암기 메뉴는 과목별로 시험 직전에 외울 숫자·기한·암기코드를 모은 페이지입니다. 내용은 [`data/core-summary.json`](data/core-summary.json)에 있고, 숫자는 2026-10-31 시험일에 시행 중인 법령 기준입니다. 과목마다 듣기 버튼이 있어 요약을 음성으로 읽어 줍니다. 음성은 미리 녹음한 파일(`audio/summary/`)이라 휴대폰 화면이 꺼져도 계속 나오고, 한 과목이 끝나면 다음 과목으로 이어집니다. 목소리는 Siri 음성 민지입니다. 요약 내용을 고친 뒤에는 macOS에서 `node scripts/build_summary_audio.js`를 실행하면 바뀐 과목만 다시 녹음하고 [`data/summary-audio.json`](data/summary-audio.json)을 갱신합니다. 이때 맥에 한국어 Siri 음성(민지)이 내려받아져 있어야 하고, 녹음하는 동안 맥의 시스템 음성을 잠시 민지로 바꿨다가 되돌립니다.

실전 모드는 모의고사 전체를 한 번에 연속 진행하는 기능이 아니라 실제 교시별 구성입니다. 빠진 과목 문항이 있으면 시작을 막고, 대시보드의 문항·개념 자료 점검에서 회차 구성을 확인할 수 있습니다.

암기카드의 **빠른 암기** 탭은 기존 개념의 정의·비교·암기 포인트를 작은 카드로 나눕니다. 1차 집중 또는 6개 분야를 골라 10·20·30장씩 학습하고, 개념 확인 후 기억 여부를 표시합니다. 헷갈린 카드만 반복할 수 있으며 진행과 복습 결과는 이 기기에 저장됩니다. 새 묶음에서는 다시 보기 표시와 연결 오답을 우선합니다. `node --test tests/quick-memory.test.cjs`로 카드 추출과 복습 순서·상태 전환을 확인할 수 있습니다.


첫 화면은 1차·2차를 골라 핵심 암기 20장, 오답·헷갈림 최대 10문제, 실전 점검을 순서대로 시작합니다. 상세 통계는 접어서 보관합니다. 최근 실전 성적은 실제 교시 구성을 완료한 기록만 사용하고, 2차 종합은 같은 회차의 두 교시가 있어야 계산합니다. 합격 기준(과목 40·평균 60)과 개인 목표(45·65)는 분리합니다. 처음 푼 문항의 정답률도 반복 풀이와 별도로 표시합니다.

`learning-engine.js`는 필수 암기 원문으로부터 카드와 비교표를 만들고 질문 본문 주제에 맞는 개념을 연결합니다. 보기에 나온 단어로 개념을 추정하지 않으며, 직접 연결한 카드와 질문 주제 연결을 함께 사용합니다. 관련 개념을 못 찾으면 해당 문항의 풀이로 복습합니다. 재풀이 중에는 개념·정답·해설을 숨깁니다. 빠른 암기는 필수 암기의 같은 내용을 사용하며, 기억 여부에 따라 1·3·7일 복습 간격을 기록합니다. 완료 후 관련 문제를 한 문항씩 확인할 수 있고, 맞혀도 헷갈리는 문항을 표시할 수 있습니다.

필수 암기의 각 항목에서 같은 주제의 카드로 이동하고, 카드에서는 용어를 검색할 수 있습니다. 대시보드의 기록 내보내기·가져오기는 JSON 파일로 기록을 합칩니다(진행 중 시험은 가져오지 않음). 문항 신고는 기기 기록을 남기고 GitHub에 제목·본문이 채워진 신고 작성 화면을 엽니다. 최종 이슈 등록은 사용자가 GitHub에서 완료하며, 앱에 GitHub 토큰을 넣지 않습니다.

배포 전에 GitHub Actions에서 구문 검사와 `node --test tests/*.test.cjs`를 실행합니다. 실제 브라우저 흐름은 서버를 실행한 후 `APP_URL=http://127.0.0.1:8000 node tests/browser/learning-flow.cjs`로 검사할 수 있습니다. Playwright가 필요하며 별도 설치 경로를 쓸 때는 `PLAYWRIGHT_MODULE`, 시스템 Chrome을 쓸 때는 `CHROME_PATH` 환경변수를 지정합니다. 이 브라우저 점검은 GitHub 신고 페이지를 가로채 실제 이슈를 전송하지 않습니다.

### 개념 카드와 오답 연결

암기 화면은 공통 개념 카탈로그를 사용합니다. 예전 문제 기반 카드의 질문·정답 필드와 선택지 번호·개별 사례 문장은 암기 내용에 포함하지 않습니다. 저장한 오답도 연결된 개념의 제목과 정의를 표시하며, 연결이 없는 문제는 오답노트의 해설로 복습합니다. 관련 개념은 문항의 질문 부분과 세부 주제가 맞는 한 장만 표시합니다.
